# Request-local reuse resets the fallback freshness clock on long ordinary reads

**Severity:** correctness / freshness regression against the original contract. **Evidence:** source inspection of frozen b76173b4c5cd5740fff46785faa3ba690d80bc40 against base 9dc95184896118c96f34493da28ce40bf5b3d8d6; scenario not yet independently executed.

`Client/SignalR/Client.fs` RequestSnapshot (lines 30–34) retains generation and verified result but no verification time. `activateReadyOnActivity` captures the snapshot before dispatch, including ordinary source reads. `checkWorkingGuidance` (lines 339–356) uses a generation-current request snapshot as its cache load regardless of age. `Client/Modules/WorkingTurnGuidance.fs:55–77` stamps successful loads with the caller's `now`, and uses a two-minute TTL. Thus an expired entry can be repopulated by a much older snapshot and appear fresh for two additional minutes. Same-agent generation checks do not address external Git writes or missed pushes; the existing TTL explicitly covers these.

Reproduction scenario: cold ordinary ReadFile/SearchText/GetGitDiff request for an already-Working agent, with a verified t0 snapshot; delay source dispatch beyond 2 min, change the canonical agent state/working-turn start outside push delivery (the documented fallback case), then finish dispatch. The old implementation's post-dispatch cache lookup expires and loads canonical state; the candidate instead reuses t0 evidence under the unchanged generation, stamps it at t1 and can emit stale or omit newly applicable STOP guidance, also affecting subsequent warm requests. This does not require bypassing CAS or permission checks. The candidate's tests exercise generations and immediate reuse, not elapsed-age expiry.

Original task obligation: unchanged freshness and response/instruction semantics. Candidate remedy (not prescribed scope): carry a verified-at time, reject request-local reuse once the existing freshness bound has elapsed, and avoid resetting the verified age of an older observation when seeding the shared cache; add a deterministic clock-controlled regression for no-push fallback.
