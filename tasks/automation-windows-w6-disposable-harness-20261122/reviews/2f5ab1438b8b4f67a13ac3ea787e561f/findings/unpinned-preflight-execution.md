# P1 — Preflight scripts execute before immutable source validation; testhost script path is unbound

**Frozen source:** `775e85dc5d70dc17a8fc1c65d7cf3baa84a53b8b`. **Original requirement:** source-pinned, independently reviewed, default-off test-only composition; parent and testhost must fail closed before any scratch or test process activity, with immutable reviewed source identities rather than an untrusted QA copy.

**Evidence (parent):** `compose.mjs` calls `nativeAttestation(opts)` at the top of `stage()`, which executes `dotnet fsi <here>/native-preflight.fsx`. Only **after FSI returns** does the script verify `git(here, "rev-parse", "HEAD") == opts["review-commit"]` and `git(here, "status", "--porcelain") == ""`. Consequently, a dirty/replaced `native-preflight.fsx` can execute before it is detected as unreviewed. The supplied `--review-commit` is itself an unchecked caller-selected SHA, not a source of independently established review authority.

**Evidence (testhost):** `W6NativeChildGuard.fs` obtains `W6_NATIVE_PREFLIGHT_SCRIPT` from process environment, checks only `Path.IsPathFullyQualified` and `File.Exists`, then launches `dotnet fsi` on that path and trusts the textual `W6_PREFLIGHT_OK phase=testhost` marker. It does not tie the script to the exact frozen reviewed blob. A caller-selected script can print the expected marker without doing the native token/known-folder/ACL checks. The preceding WQ11 in-process guard provides some genuine independent checks but does not make this script/content attestation source-bound.

**Impact:** Source-only `--check` verifies known blobs, but the actionable Windows `--stage` and future child guard have an execution-before-pinning path. This violates the original fail-closed, reviewed-source precondition. No native Windows test was attempted; the analysis follows source call ordering and trust inputs.

**Bounded corrective direction:** Before starting any FSI interpreter, verify the exact approved preflight script bytes and reviewed harness identity with a trusted/immutable source pin and reject dirty or relocated scripts; supply a hard-bound approved child preflight path/hash rather than accepting an environment-selected arbitrary executable script. Preserve default-off behavior. Add explicit negative controls for modified preflight content and a child script that prints the expected success marker without performing checks. Keep the production W6/WQ11 blobs untouched and avoid Windows execution until separately authorized.
