[P1][Browser audit] Verify deployed browser bridge and recurring agent launches end to end

Finding

Source tests and a ready browser registration do not prove production launches. The inspected live extension version was unverified; previous recurring attempts failed with WindowUnavailable:needsReauthorization. The remaining four schedules have not been positively witnessed launching and submitting once after cleanup.

Required work

Build an operator-gated, source-pinned release acceptance procedure: verify installed Edge extension, local client, deployed server compatibility, registered window readiness and current launcher file. First use no-submit probes; then obtain explicit operator authorization for controlled real prompt sends if needed. Observe one complete approved recurrence per logical Manager/Health schedule and confirm creation, exact-once initial submission, close behavior, and no duplicate activations. Exercise restart/reauthorization and explicit stop/cancel scenarios in a controlled fixture where feasible. Do not equate failed retries, a blank registered-tab listing, or successful service health with delivered conversation turns.

Acceptance criteria

  • Record exact installed extension/client/server/launcher versions, registered window generation and environment under test.
  • No-submit probe passes through installed extension without opening unauthorized persistent conversations.
  • With explicit operator approval, a bounded canary proves initial prompt submission exactly once and proper tab reclamation; never infer uncertain submission should be replayed.
  • Observe and reconcile the four canonical approved recurring schedules without duplicate logical agent activation, respecting their actual recurrence configuration.
  • Restart and registration failure cases produce actionable status; resulting acceptance report separates observed behavior from inferred behavior and marks pass/fail for each.

Evidence and starting points

Audit 20 Nov: registered main transitioned needsReauthorization/generation 4 to ready/generation 5; ten schedules reduced to four; no successful next-cycle real launch verified.

Boundaries

Writing this task does not authorize deployment, changes to live schedules, live prompt sends, or agent launch. Coordinate with existing work and use actual test and runtime evidence before completion.
