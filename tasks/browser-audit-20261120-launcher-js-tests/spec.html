[P1][Browser audit] Reconcile ChatGPT launcher tests with current model and effort picker

Finding

Node suite: 146 total tests, 82 pass and 64 fail. The failures cluster in browser-extension/tests/chatgpt-launcher.test.cjs: its synthetic DOM omits the model/effort picker required by current browser-scripts/chatgpt/launchAgent.js, causing notSubmitted before intended scenarios.

Required work

Audit implementation and harness against current real ChatGPT UI. Update fixtures and test assertions for supported model and thinking effort selection, including a realistic fallback when UI controls are absent or change. Preserve scenario intent: each existing submission, mode-selection, draft/hydration, failure classification, and cleanup test must reach the behavior it claims to test. Correct actual implementation defects discovered rather than weakening tests to force green.

Acceptance criteria

  • Run node --test browser-extension/tests/bridge.test.cjs browser-extension/tests/chatgpt-launcher.test.cjs browser-extension/tests/popup.test.cjs with zero failures.
  • Tests explicitly exercise picker present, picker absent, delayed hydration/re-render, unsupported selection, and no-prompt-sent conditions.
  • Submission tests assert exactly one send; uncertain post-injection outcomes must not trigger replay.
  • An installed-extension smoke probe verifies the DOM assumptions without unintended prompt submission.

Evidence and starting points

Audit 20 Nov 2026: 64 launcher suite failures in otherwise passing bridge/popup suite; browser-scripts/chatgpt/launchAgent.js and browser-extension/tests/chatgpt-launcher.test.cjs.

Boundaries

Do not launch agents, change running schedules, deploy, or perform live prompt submissions as a side effect of this task's creation. Preserve exact-once/uncertain-outcome semantics and verify the implementation before marking complete.
