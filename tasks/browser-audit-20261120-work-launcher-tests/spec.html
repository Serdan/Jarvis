[P1][Browser audit] Add dedicated regression coverage for ChatGPT Work launcher

Finding

browser-scripts/chatgpt/launchWorkAgent.js has no dedicated test coverage; the existing launchAgent.js suite does not establish Work-specific behavior, including hydration and Work/Chat mode transitions.

Required work

Build isolated, deterministic tests around the production Work launcher using a representative DOM and direct execution entrypoint. Cover Work-mode selection through hydration/rerender, composer population, exact-once submission, unsupported UI, pre-send failure, and post-send uncertainty. Verify behavior against a no-submit installed-extension probe. Share a fixture abstraction with launchAgent tests only if it reduces duplication without hiding real UI differences.

Acceptance criteria

  • New dedicated launcher suite runs in the repository's standard node test invocation and is included in CI/release verification.
  • Positive Work path proves exactly one submitted turn; negative paths prove no unexpected send or replay.
  • Hydration, mode toggles, model/effort selection when applicable, changed selectors, and tab cleanup each have targeted regression tests.
  • Test evidence distinguishes simulated DOM behavior from live installed-extension acceptance.

Evidence and starting points

browser-scripts/chatgpt/launchWorkAgent.js; no occurrences of its entrypoint in browser-extension/tests at audit.

Boundaries

Do not launch agents, change running schedules, deploy, or perform live prompt submissions as a side effect of this task's creation. Preserve exact-once/uncertain-outcome semantics and verify the implementation before marking complete.
