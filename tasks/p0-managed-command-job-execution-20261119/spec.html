Reproduced problem and source

On operator Linux client, run_command sleep 8 with timeoutSeconds=3 returned a pollable ToolOperation but killed the subprocess (ToolCompleted, ExitCode=-1, TimedOut=true); timeoutSeconds=20 completed; start_job sleep 9 reached real exit via get_job_result. Current Client/Modules/ClientShell.fs Core.defaultTimeoutSeconds=60 invokes BoundedProcess.run with process lifetime timeout; Client/SignalR/Client.fs sends a ToolOperation after approximately 3 seconds but does not suspend the actual process lifetime; Client/Modules/JobManager.fs already provides managed job lifecycle. The tool-operation handle is not itself proof the OS process finished.
