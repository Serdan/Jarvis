## Clean exact checkout can be falsely attested (original task obligation)

**Source:** b21efb32a21a0d2cb473add5a0b7c0288ea2a795, `scripts/release-provenance-publisher-composition/publish.py`, `observation`.

The new boundary equates empty `git status --porcelain=v1 --untracked-files=all` with a clean exact source. Git's assume-unchanged index bit suppresses tracked worktree modifications even with this invocation; skip-worktree and sparse checkout also merit explicit handling. The candidate then records the false clean observation in its build receipt. The task explicitly requires clean exact source/tree and fail-closed dirty evidence. This is not a request for hostile-toolchain resistance or new deployment policy.

Independent actual reproduction: extracted `publish.py` and accepted `verify.py` from the exact frozen Git object into a disposable temporary directory, initialized a separate Git repo, committed `source.txt` containing `original`, captured HEAD/tree, ran `git update-index --assume-unchanged source.txt`, changed its contents to `modified`, and invoked `publish.observation(repo, source, 'before-build')`. Exit 0; returned `status: clean`, `method: git-status-porcelain-v1-untracked-all`, while independently comparing bytes to `git show HEAD:source.txt` returned `worktree differs True` and `git ls-files -v` returned `h source.txt`. No real build, deployment, network or shared source modifications. The existing pinned artifact digest mitigates accepting arbitrary substituted output but does not make the claimed clean checkout observation true; unchanged output can coexist with dirty source. The current ordinary dirty controls miss the index-bit case.

Candidate remedy (not a prescribed new requirement): reject hidden/sparse index states or independently verify tracked worktree contents and modes against the pinned tree, consistent with documented trusted checkout assumptions; add an offline negative control at the actual boundary. Consider explicit submodule handling if relevant. Adjudicate proportionality independently; the defect is an unfulfilled original clean-source obligation.
