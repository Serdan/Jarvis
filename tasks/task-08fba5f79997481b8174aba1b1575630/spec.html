[P2] Remove closed browser tabs from extension registration registry

Bug: Closing a browser tab leaves it listed under the Jarvis Browser Bridge extension's Registered tabs as needsReauthorization. Verified in current browser-extension/background.js: chrome.tabs.onRemoved calls observeNavigation(tabId, null, true), which permanently marks a closed registration blocked. assess short-circuits blocked registrations before checking tab existence, and refreshRegistrations never prunes missing tabs. This stale entry is persisted in chrome.storage.local and advertised to client; both manually registered and Jarvis-created tabs are affected.

Implementation

  • On a real chrome.tabs.onRemoved event, remove the affected registration from the extension registry, persist the new registry, and re-advertise. Only closed tab registrations are removed; closing a registered tab does not grant permission to another tab.
  • On extension startup, reconnect, or listing, reconcile registrations for tabs that no longer exist so persisted orphan entries from earlier versions disappear, even if marked blocked or associated with a previous session epoch. Preserve registrations that still exist but need reauthorization due to navigation, origin revocation, tab relocation, disabled agent-tab permission or restarted browser session.
  • Keep BrowserCloseTab restricted to verified Jarvis-created tabs; user-closing a manual or agent-created tab should simply remove its registration. Handle duplicate onRemoved and explicit close cleanup idempotently. Do not delete existing tab records merely because the extension was temporarily disconnected.
  • Respect concurrency while async refresh, close and tab-removal events overlap: a stale refresh must not resurrect a removed registration or lose a concurrently added registration.

Acceptance

  1. Node simulated Chrome tests cover closing manual and agent-created tabs, unrelated tabs, double cleanup after explicit BrowserCloseTab, stale persisted blocked/missing entries on cold extension startup and listing, navigation reauthorization for existing tabs, and re-advertising a removed registration to Jarvis.
  2. Run node --test browser-extension/tests/bridge.test.cjs browser-extension/tests/chatgpt-launcher.test.cjs and relevant .NET 11 Release bridge tests; validate safe extension reload expectations. Use an isolated worktree, self-contained frozen independent review; do not merge/deploy without operator approval.
