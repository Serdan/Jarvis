The wrapper prevents completion that should succeed. Freshest Stopped + assigned case requires separately checking state-source/cache and valid recovery path.
  • ObserveAgentCommand and JarvisMcpTools.ObserveAgent already exist in source, but are not surfaced by the currently available ChatGPT Jarvis connector actions, so read-only inspection may be inaccessible to an affected user.
