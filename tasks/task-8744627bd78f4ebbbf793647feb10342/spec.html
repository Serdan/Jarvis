Windows bounded-process pipe forwarding

KRUSO Windows protocol 3.62 reports FinanceFlow InvalidBinding despite the Git origin fetch and push URLs matching the persisted approved binding exactly. BoundedProcess-based git remote get-url, git status and git log return exit 0 with empty captured stdout on Windows; StartJob returns correct Git stdout. The Windows process-group helper launches its target without forwarding redirected standard handles. Restore byte-preserving stdout/stderr and stdin handling through the helper while preserving job-object startup barrier, timeout, termination and security semantics.

Acceptance criteria

  • BoundedProcess on Windows returns actual Git stdout and stderr, without truncation or encoding regression; run_command, get_git_status and ledger validation work.
  • Preserve child stdin EOF/text behavior, bounded output, deadlines and descendant termination.
  • Add a regression for Windows process-group forwarding; run Release tests and submit independent review.
  • Do not change FinanceFlow remote URL or Jarvis trust binding to work around capture loss; separate coordinated client release requires operator authorization.
