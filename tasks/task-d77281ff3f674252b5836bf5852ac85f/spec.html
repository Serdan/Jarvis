Workspace project creation

Add a first-class create_project MCP command to create a new direct child folder of the configured Jarvis workspace. Existing project creation via mkdir must remain valid.

Acceptance

  1. Validate a single safe project folder name, refuse preexisting path, symbolic links or escaping workspace; no parent tree traversal.
  2. Optional local Git initialization; optional project .jarvis.json and AGENTS.md starters with sensible defaults and no unexpected overwrite.
  3. Optional ledger initialization integrated with existing trusted ledger binding and explicit remote/trust acknowledgments; avoid silently inventing remote trust or creating ledger for plain folders. Make partial failures explicit.
  4. Expose command through Common protocol, client handler, capability/permission catalog, MCP server, and tests; show newly created project in list_projects.
  5. Build and test in Release; self-review, integrate through normal merge, do not deploy without operator approval.
