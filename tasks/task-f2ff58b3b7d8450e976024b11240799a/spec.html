Bound AgentDashboard notification parse cache memory

Priority: P3. Finding: JRV-2026-11-09. Review: docs/reviews/2026-11-07-deep-review.md (baseline e50c24af).

Problem

AgentDashboard.parsedNotifications is a process-global ConcurrentDictionary keyed by full JSON content with no eviction. Every unique historical notification stays in memory for the lifetime of the client even though project snapshot caches already exist.

Relevant code

Client/Modules/AgentDashboard.fs:33-42,54-75,85-92,150-161; Client.Tests/AgentViewTests.fs; Client.Tests/ActivityPresentationTests.fs

Implementation requirements

  1. Replace the unbounded global notification JSON cache with a bounded ownership/lifetime strategy. Prefer simple snapshot-scoped parsing or a small bounded cache keyed by stable OID if measured parsing costs justify retaining it.
  2. Keep coherent semantics across changing Git heads and across multiple projects; ensure per-agent unread counts and latest-notification summaries remain correct even after history grows or entries are evicted.
  3. Do not retain duplicate full JSON strings indefinitely, and bound memory independent of total notifications ever observed in a client lifetime. Measure allocations and refresh latency before and after.
  4. Minimize changes to the AgentDashboard output types or canonical ledger paths, and do not introduce a server-owned cache.

Acceptance / verification

  • Under a fixture with large historical notification volumes and repeated new snapshots, memory retained by caches stays bounded as old heads age out.
  • Tests validate project switching, snapshot reuse, repeated refresh, eviction, acknowledgement and latest-notification order with no lost or stale unread indicators.
  • Client Release tests pass; a performance note states cache limits and before/after memory or allocation measurements.

Boundaries

No need for an LRU framework if cheaper scoped data structures suffice.

Review the design and implementation; correct findings and re-review until accepted. Prefer long-term correctness to quick fixes.
