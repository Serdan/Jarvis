# P1 — original C1 queue/account snapshots are not fully bound to the projected authority

**Frozen candidate:** `d6f49a6c8b29d645e4641a0595a704190e30e3ed`.

`buildProject` reads the imported `legacy-queue` and `legacy-composition`, then checks only version/graph identifiers and the *keys* of `Works`, `Subscriptions`, and `Launches` (`Server/WorkLegacyImportProjection.fs:270-284`). It does not require the imported stage/role/graph bodies to equal `WorkLegacyImportInspection` or a canonical digest. The per-stage comparison checks `State.case`, `Gate.case`, dependency keys, waiver **keys** rather than waiver receipt values, and some origin metadata, but not the full original stage/domain/push/authorization/effect payload (`:308-341`). `legacy-account` is checked only by `SourceSha`, not by its stored JSON (`:458-460`). The normalized Scheduler snapshot is constructed from `inspection.Projects`, not from a decoded, exact immutable C1 source (`:406-414`, `:461-493`).

**Source-level counterexamples:** change `legacy-queue.Works[workId]`'s body fields (or `legacy-account`'s JSON) in disposable SQLite while leaving the row `SourceSha`, graph/queue versions and key sets unchanged. The projection's comparisons cannot see this change, and its CAS guard only seals the *currently observed*, possibly modified row, not the originally imported value. Likewise, changing waiver receipt values with the same keys, or a gate payload with the same union case, is not detected by the predicates shown. The existing four-tamper test mutates the stage gate case, role queue names, origin ref, or `ExternalEffect`; it does not exercise equal-key/different-payload drift (`Server.Tests/WorkLegacyImportProjectionTests.fs:390-430`).

This fails the task's requirement that original imported source/identity/authorization/waiver/provenance be transactionally bound before writing `coverage=Verified` and that original import remain immutable. **Required correction:** compare a complete canonical decoded source or authenticated hash for original C1 project/account/role/stage/graph rows (or isolate byte-for-byte immutable originals in a separate keyspace and project into new rows), with exact negative tampering tests for retained payloads, including waiver receipts and STOP/source identity. Do not call an E0 green test evidence of original C1 source equivalence until these predicates are closed.
