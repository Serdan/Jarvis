# P1 — C2 original-writer fence is not checked against the complete retained audit

**Frozen candidate:** `d6f49a6c8b29d645e4641a0595a704190e30e3ed` (`Server/WorkLegacyImportProjection.fs:177-247`).

`verifiedFence` uses the C2 source receipt set as a prerequisite for elevating a C1 import to `coverage=Verified`, but its comparison to the transactionally retained `legacy-import-c2-authority-audit` checks only `EntityId`, `LedgerId`, `FencedHead`, `AuditSha256`, `WriterGeneration`, and `AllOriginalClientsQuiesced` (`:233-245`). Its earlier predicate only requires pending-intent/source-effect high-water to be **nonnegative** (`:225-232`). The original C2 audit explicitly retains additional binding and evidence fields: `Scope`, `LedgerEpoch`, `DeviceId`, `TrustedRemoteId`, `OriginalHead`, `FenceHighWater`, `ExclusiveReceiptId`, `OriginalPendingIntentHighWater`, `OriginalSourceEffectHighWater`, `MinimumClientProtocolVersion`, `AllClientQuiescenceProofSha256`, etc. (`Server/WorkLegacyImportFence.fs:219-240`).

**Source-level counterexample:** alter a C2 receipt's `OriginalPendingIntentHighWater` (e.g. 1→0) or `Binding.Scope` / `OriginalHead` while retaining all fields this projection compares. The projection has no predicate requiring the altered field to match the retained C2 audit and may still mark the normalized project `Verified`. The existing test only corrupts `AllOriginalClientsQuiesced`, a field that *is* compared (`WorkLegacyImportProjectionTests.fs:435-446`). This is not a fully reproduced runtime exploit; it is a missing equality predicate on a safety-critical trust boundary.

**Required correction:** validate each C2 receipt against the **complete exact** authenticated import/plan and persisted audit (scope, original account/project ledger identity, source/ref/head, decision/fence/exclusive ID, generations, all high-water counters and quiescence proof), including uniqueness and valid authenticity/digests. Unknown or drifted values must return `Incomplete`, with negative tests that mutate fields not previously compared. Do not weaken E0's verification or activate live migration.
