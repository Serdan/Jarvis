# F03 — P1 — Cross-session source handoff is underspecified

**Frozen source:** lines 15–16, 34, 57, 106–110, 160–172, 198–208, 267–274, 298–299, 311.
**Related existing contract:** docs/OrchestrationMigration.md lines 162–166 (`SetAttemptSource` pins initial baseOid/targetRef and repository identity); docs/ManagedReviewIntegration.md (exact remote review/integration refs).

**Finding.** A checkpoint's source SHA is optional, and the design mentions source refs/history without specifying a portable, immutable **resumable source snapshot**. A worker can create uncommitted edits, commit only in a private local worktree, or move a task branch after checkpoint. Worker B on a different device may read a valid summary but cannot reconstruct the exact files. A mutable branch name is insufficient; a recorded SHA without remote reachability is also insufficient. Yield atomically freeing a work claim does not itself make source state durable. Lines 206–208 correctly guard mutating jobs but do not address ordinary dirty worktrees or unreachable commits.

**Required design resolution.** Define a source-handoff precondition per work type: no source mutations, or an exact repository identity + pinned baseline + commit OID + stable reachable ref (or equivalent durable artifact) and verified clean/consistent source state before source-writing work becomes Available. Record the handoff in the same logical yield outcome or fail the yield safely (e.g. block with an explicit dependency); never silently resume at a stale branch HEAD. Preserve the pinned original baseline and target separately from a changing WIP tip and from immutable accepted review SHA. Specify how pre-existing source bindings, rewrites, untracked/dirty files, and in-flight mutating jobs affect requeue and recovery.

**Required tests.** Worker A makes changes in a dirty worktree and attempts YieldWork; no false successful portable handoff. Unpushed local commit cannot be claimed from a different client. Force-pushed branch after checkpoint cannot change B's materialized source. Two independent machines retrieve exactly the pinned WIP snapshot, with the original base/target preserved. Crash after snapshot publication but before ledger yield reconciles idempotently without duplicate or lost work. Preserve existing legacy attempt source bindings through migration.
