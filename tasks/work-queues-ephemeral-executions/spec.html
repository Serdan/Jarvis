Current decisions to preserve

  • Remove model Manager: non-agent Scheduler/Reconciler is the only automatic launch/control plane; one global account-capacity semaphore across projects/roles, no Manager slot handoff or model-session scheduler polling.
  • Blocking-first FIFO: Ready work that is a hard unsatisfied prerequisite of another unfinished stage is scheduled before ordinary Ready work; otherwise FIFO by server-witnessed availability. Requeued/yielded work enters back of tier. Blocked work cannot run. Compatible injective demand-credit matching prevents duplicate/stranded launches.
  • Circular hard dependencies: derive stage-generation graph SCC/self-loop warnings (Tarjan O(V+E)) with exact witness and Lead/operator attention. Do not reject edits or make blocked cycle members runnable. Incomplete coverage fails closed.
  • Connection identity: Scheduler reserves/dispatches stable launchId with role/pinned config; agent UUID is not created until InitializeAgent(launchId, sessionKey, operationId) on the actual session connection. Same-session replay is idempotent; competing sessions cannot bind a second UUID. Task ID comes from atomic work claim, not bootstrap.
  • Minimal bootstrap: launch reference (possibly bridge-injected) plus instruction to connect/initialize; Jarvis supplies role instructions, task spec, frozen SHA, checkpoints and Task/Role conversation.
  • Task/Role operator messages: durable recipient by Task(project,id) or Role(project,id), including Lead. First eligible handler CAS wins responsibility; message persists across UUIDs; ancillary role handling preserves pending launch-demand credits. Existing STOP response alerts target registered agent UUIDs only.
  • Recovery and exact evidence: C01 global-first project abort tombstone; unregistered and registered/no-claim/claimed lease recovery fences; independently verified project terminal before account token release; no blind browser retries or use of tab closure as terminal proof.
  • Source and domain invariants: one source writer per lineage, remote durable WIP continuation, canonical frozen review/verdict and integration of exact accepted SHA, challenge-backed operator consent, complete Git-ledger index/graph coverage and staged project/account migration epochs.
  • Permissions: Agent IDs/roles are cooperative handles under current owner account permissions, not identity security principals or per-role ACLs. Future contributors are account-scoped.
