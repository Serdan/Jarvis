Decisions to preserve

  • Lead prioritizes canonical task/queue work; Scheduler spawns Manager only when the account-global limit permits; Manager launches ephemeral sessions with assigned roles; Workers claim the highest-priority eligible item atomically, never by fixed Worker N ID.
  • Client auto-numbers simultaneously displayed agents of the same role, but opaque execution IDs are the only durable attribution; agent labels are not security or permission boundaries.
  • One maxConcurrentAgents across all roles/projects/devices, including Manager and Lead, with non-agent scheduler preflight and fail-closed uncertain launches; last free slot may be passed by a single-use terminal Manager-to-child handoff.
  • Tasks retain durable checkpoints, portable source snapshots and operator conversation/question/answer histories across ephemeral sessions. Canonical Git-backed project work ledger and separate account-global admission ledger preserve their own authoritative domains.
  • Frozen review verdicts, exact integration SHA, challenge/consent evidence, and source-writer lineages remain independently canonical; negative-space concurrency and migration tests are required.
