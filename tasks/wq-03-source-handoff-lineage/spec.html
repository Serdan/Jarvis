Scope

  • Bind source-writing stage to repository, target, immutable base, lineage ID, stage generation and active writer; enforce one actionable writer per lineage using canonical CAS.
  • Before normal yield, create/publish an immutable generation-scoped WIP Git ref, verify exact commit SHA reachable remotely, store provenance/checkpoint; reject dirty or unreachable source that cannot be handed off.
  • Prevent untracked mutating jobs and stale predecessor activations from releasing claims or overwriting new lineage state; preserve WIP history across devices.
  • Coalesce compatible correction findings without allowing two conflicting writers; explicit separate lineage needed for true parallel branches.

Acceptance

  • Worker B on a different device resumes the exact tracked/untracked committed source snapshot after Worker A yielded; predecessor worktree is not required.
  • Dirty unpublished source, unpushed local commit, overwritten mutable ref and active mutating job cannot produce false successful requeue.
  • Two ChangesRequested reviews on one source lineage result in at most one current writer; stale correction cannot regress latest source.

Exclusions

No review verdict duplication, no merging source to main. Use an isolated worktree; Release tests and independent frozen review are required before exact reviewed integration. Do not use Codex through Jarvis. This task is not deployment/scheduler authorization.
