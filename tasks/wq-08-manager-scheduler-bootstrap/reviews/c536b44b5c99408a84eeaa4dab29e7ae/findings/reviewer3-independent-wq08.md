3. **Global-first/project-second and C01:** `reserveAccount` delegates to WQ07 `reserveGlobal` using the pinned account version and operation ID. `admitAfterReserve` demands the live launch token and matching original reserve receipt before the project CAS, then verifies original work generation and matching credited work. No cross-ledger transaction or authoritative external Git confirmation is claimed in this simulator.

4. **First-connect UUID/session CAS:** `initializeFirstConnect` requires a submitted-unregistered launch, expected project version, original-operation payload compatibility, pinned role ID/version/subscription and instruction reference, and nonempty session key. It allocates a valid nonzero GUID candidate only on the eligible unregistered path, rejects a collision with another registered launch, and delegates the project CAS to WQ07 `initializeAgent`. The committed winner stores exactly one UUID/session binding and lease generation; an identical session-key replay returns the original UUID/lease without allocating another UUID, even after an unrelated project version advance. A different session key is `AlreadyRegistered`, stale first registration is `CasConflict`, and terminal or invalidated launches cannot re-register. A distinct operation ID with the *same* registered session key is treated as a read-only idempotent response, not a second registration. The bootstrap returns instruction digest/queues, not unverified instruction contents. The helper `sessionKeyForExecution` is inherited from WQ07 and is only a pure session-key continuity fixture, not a provider identity or entropy source.

5. **Browser uncertainty, deadline and wake:** `dispatchAdvice` returns only `ReconcileOriginal` on `OutcomeUnknown`, never a second browser-send intent; WQ07 `dispatchOnce` restricts dispatch count to one. `expireUnregistered` requires an elapsed deadline, asserted original journal settlement, an original-dispatch receipt for the same launch, and a project terminal CAS before token release; a late `InitializeAgent` then rejects. `coalesceWake` calculates a bounded fallback/pending flag without a running timer, process, or model token.
